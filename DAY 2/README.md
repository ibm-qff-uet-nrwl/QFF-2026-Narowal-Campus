## 📁 Repository Contents / ذخیرے کا مواد

### Presentations (`/presentations`)
* `Measurement_QFF.pptx` — Covers core measurement mechanics and state collapse.
* `Bloch_Sphere_QFF_Final.pptx` — Geometric representation of single-qubit pure and mixed states.
* `Qiskit_Patterns_QFF.pptx` — Introduction to the four-step execution framework (Map, Optimize, Execute, Post-process).
* `Sampler_Primitive_QFF.pptx` — Architecture and usage of the Sampler primitive for quasi-probabilities.
* `Estimator_Primitive_QFF.pptx` — Computing expectation values of observables via the Estimator primitive.

### Practical Lab Notebooks (`/labs`)
* `Quantum_Measurement_Lab.ipynb` — Hands-on exercises exploring projection operators and measurement statistics.
* `Bloch_Sphere_Visualization_Lab.ipynb` — Interactive single-qubit rotations and state mapping on the Bloch sphere.
* `Introduction_to_Quantum_State_Tomography_Lab.ipynb` — Reconstructing density matrices from experimental measurement data.
* `Qiskit_Patterns_Map_Optimize_Execute_Post_Process_Lab.ipynb` — Implementation of the complete Qiskit runtime pattern pipeline.
* `Sampler_Primitive_Code_Lab_Guide.ipynb` — Coding walkthrough for submitting circuits using `SamplerV2`.
* `Estimator_Primitive_Code_Lab_Guide.ipynb` — Coding walkthrough for calculating expectation values using `EstimatorV2`.
