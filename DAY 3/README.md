# Day 3: Multi-Qubit Circuits & Entanglement
# دن 3: ملٹی کیوبٹ سرکٹس اور انٹینگلمنٹ

Welcome to the **Day 3** repository materials for **Qiskit Fall Fest 2026** at the University of Engineering and Technology (UET) Lahore, Narowal Campus[cite: 2, 9]. This session explores multi-qubit state spaces, tensor products, quantum entanglement, Bell states, GHZ states, and quantum teleportation protocols[cite: 4, 9, 10, 14, 15].
